# Ssshmul Downloader

מערכת חכמה, מהירה ומתקדמת להורדת מוזיקה ושירים מיוטיוב ומגוון פלטפורמות, עם מעקב אוטומטי אחר אמנים, תמיכה בתוסף דפדפן ייעודי וממשק משתמש נוח ומודרני.

---

##  תכונות עיקריות (Features)

-  **הורדת שירים ואלבומים באיכות גבוהה**: המרה אוטומטית ל-MP3 ותיוג מטא-דאטה עשיר.
-  **מעקב חכם אחר אמנים (Artist Tracking)**: זיהוי ערוצי יוטיוב / רשימות השמעה וסריקה אוטומטית של שירים חדשים.
-  **אינטגרציה מלאה עם תוסף כרום (Browser Extension)**:
  - הורדת שירים בלחיצה אחת ישירות מעמוד היוטיוב.
  - סנכרון עוגיות (Cookies) של הדפדפן להתגברות על חסימות בוטים / הגבלות יוטיוב.
  - חיווי סטטוס חיבור בזמן אמת והוראות התקנה מפורטות.
-  **מנוע חזק ומהיר**: מבוסס על `yt-dlp` ו-`FFmpeg` מותאמים אישית.
-  **שרת רקע מקומי (Local WebSocket Server)**: תקשורת דו-כיוונית רציפה בין ממשק הדפדפן לתוכנת ההורדות.

---

##  התקנה והרצה (Getting Started)

### דרישות מערכת:
- מערכת הפעלה Windows
- .NET 8.0 SDK / Runtime ומעלה

### הרצת האפליקציה:
1. שכפל את המאגר (Clone):
   ```bash
   git clone https://github.com/SSSHMUEL/-Ssshmul-Downloader.git
   ```
2. פתח את הפרויקט ב-Visual Studio או הרץ דרך הטרמינל:
   ```bash
   dotnet run
   ```

---

##  התקנת תוסף הדפדפן (Chrome Extension)

1. פתח את הדפדפן ועבור לכתובת: `chrome://extensions`
2. הפעל את **מצב מפתח (Developer mode)** בפינה העליונה.
3. לחץ על **Load unpacked (טען תוסף לא ארוז)** ובחר בתיקיית `extension` מתוך הפרויקט.
4. ודא שהתוכנה הראשית פועלת ברקע – התוסף יתחבר אוטומטית לשרת המקומי!
