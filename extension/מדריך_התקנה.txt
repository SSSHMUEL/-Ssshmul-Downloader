# מדריך התקנת תוסף Ssshmul Downloader לדפדפן Chrome / Edge

התוסף מאפשר להוריד שירים וסרטונים ישירות מכפתורי הורדה שנוספים ביוטיוב!

## שלבי ההתקנה (פשוט ומהיר - 3 צעדים):

1. **פתיחת מסך התוספים בדפדפן:**
   * בדפדפן Google Chrome: היכנסו לכתובת `chrome://extensions`
   * בדפדפן Microsoft Edge: היכנסו לכתובת `edge://extensions`
   * בדפדפן Brave: היכנסו לכתובת `brave://extensions`

2. **הפעלת "מצב מפתח" (Developer mode):**
   * הפעילו את מתג "מצב מפתח" (נמצא בפינה העליונה של המסך בדפדפן).

3. **טעינת התוסף:**
   * לחצו על הכפתור **"טעינת תוסף לא ארוז"** (*Load unpacked*).
   * בחרו בתיקייה זו (`extension`).
   *(או פשוט גררו את כל תיקיית `extension` ישירות לתוך חלון התוספים בדפדפן!)*
